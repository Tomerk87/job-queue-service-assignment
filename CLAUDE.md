# Claude Code Project Instructions (v1.1)

Read and follow `AGENTS.md` in full before modifying files.

At the start of **every phase**, read:
- `TECHNICAL_SPEC.md` — authoritative architecture, API contracts, state transitions, quality goals and EC-01..EC-20 edge-case matrix.
- `PLAN.md` — current phase, implementation/test/quality/DoD checkboxes, execution evidence and human-approval gate.

Implement **only the explicitly authorized phase**. Mark `[x]` only for verified implementation or tests **actually executed and passed**; update the phase status and evidence honestly. Run tests, report actual coverage/results and perform a simplicity/efficiency review. Stop after the phase and request human approval before continuing. Do not change approved architecture without permission.
